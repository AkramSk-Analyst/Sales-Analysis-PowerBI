# Sales Analysis – Power BI

## 📊 Project Overview

Interactive Power BI dashboard analyzing key business metrics, sales trends, and performance insights through data-driven visualizations.

## 🛠️ Tools Used

* Power BI
* Power Query
* DAX
* Excel

## 📈 Dashboard Features

* Key business performance KPIs
* Sales trend analysis
* Category and product performance
* Regional/segment analysis
* Interactive filters and visualizations
* Data-driven business insights

## 🎯 Objective

To transform raw sales data into an interactive dashboard that helps identify trends, monitor performance, and support data-driven decision-making.
